Validation PASS

All eight JavaScript blocks passed Node syntax validation. The fully patched data model also executed successfully with no duplicate item IDs, no broken batch references, no broken comparison references, and no self-comparisons.

M10 · Urinary System

Renal corpuscle is now graded. The source is a 1546×1201 real renal-corpuscle micrograph using PAS. The card explicitly says PAS so students are not taught that the appearance is routine H&E.

The new kidney batch is medulla → renal tubules → renal corpuscle, followed by ureter vs bladder. A new renal-corpuscle-vs-tubules comparison reinforces “glomerular tuft inside Bowman’s space” versus an epithelial tube.

PCT vs DCT remains held. The dedicated PCT source can still be reviewed, but the only readily available field explicitly marking both PCT and DCT is annotated and low resolution. v13 does not turn that into a graded unknown.

M11 · Endocrine source audit

Posterior pituitary remains held. The apparently attractive 2996×1562 “Pituitary histology” candidate was visually audited and is actually a hand-drawn teaching plate. It is therefore rejected as a practical micrograph despite its resolution and permissive reuse terms.

M12 · Lymphoid / Immune

A new human H&E Hassall-corpuscle review card is included. It is explicitly human and useful for structure-level learning, but it stays review-only because a close-up Hassall corpuscle does not replace a clean low-power human thymus overview.

Whole thymus and routine-H&E tonsil remain on hold. The labelled human thymus field is unsuitable for unknown-slide testing, and the high-resolution file named “Histology of palatine tonsil” was visually confirmed to be a labelled hand drawing rather than a micrograph.

M13 · Integumentary System

Apocrine sweat gland is now graded. The human axillary histology field shows the visual features we actually want students to recognize: large lumina, abundant eosinophilic secretory cytoplasm and apical secretory blebs.

Eccrine remains review-only. The available 4912×3264 real histology file is useful, but the image itself contains a pointer and text overlay. v13 keeps it as source review instead of presenting it as an unknown practical slide.

M16 · Female Reproductive System

Vagina is now graded. The primary source is a 2816×2112 public-domain human vaginal-wall micrograph. An independent human histology field is retained as a second variant.

The female module is now split into four cleaner batches: ovary/tube → endometrial phase → cervix/vagina → mammary states. A dedicated cervix-vs-vagina comparison is active: cervix is identified through transformation-zone or mucinous-gland context, whereas vagina shows gland-free nonkeratinized stratified squamous mucosa.
